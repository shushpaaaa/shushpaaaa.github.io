# olzhas.app

Personal engineering portfolio for **Olzhas Huseynzade** — Computer Science & Technology at Harbin Institute of Technology, Shenzhen (HITSZ).

**Live:** [https://olzhas.app](https://olzhas.app)

---

### Architecture & Craft

- **Full-Bleed 3D Topological Manifold** — Built with Three.js (`r128`): parametric torus-knot wireframe, soft vertex cloud, faceted obsidian core, meridian orbits, and exponential depth fog (`THREE.FogExp2`) with drag-to-orbit inertia and `IntersectionObserver` power gating.
- **Editorial Typography** — `Geist` + italicized `Instrument Serif` + `Geist Mono` (`tabular-nums`) with balanced headings and strict Unslop color/surface discipline.
- **Interactive GeoShift Telemetry Preview** — Live coordinate dispatch viewport simulating `usbmuxd` DVT location packets with city presets and one-click hardware GPS restoration.
- **Smooth Choreography** — Lenis inertia scrolling paired with GSAP `ScrollTrigger` reveals and a keyboard-navigable (`⌘K`) slide-out Projects Hub synced live with the GitHub API.
- **Interactive Node Shell** — In-page CLI supporting command history (`↑` / `↓`), `Tab` completion, and project/stack queries.
