GeoShift — Native iOS GPS Simulation Controller

A lightweight cross-platform desktop instrument engineered in Rust (Tauri v2) with a Python DVT protocol bridge to simulate iOS GPS telemetry over physical USB connections. Communicates directly with Apple's developer instrumentation daemon (com.apple.dt.simulatelocation) without jailbreak or persistent OS modifications, with instant one-click satellite restoration.
